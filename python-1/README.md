# Python 1

Essa é a minha primeira atividade de Python resolvida! 🐍

Os exercícios estão divididos em níveis, do mais fácil pro mais difícil.

## O que tem em cada nível

- **Nível 1:** contas básicas, média de notas e conversão de temperatura
- **Nível 2:** par ou ímpar, maior número e uma calculadora
- **Nível 3:** tabuada, soma até digitar 0 e senha
- **Nível 4:** listas, contar vogais e palíndromo
- **Nível 5:** funções
- **Nível 6:** dicionários e sets
- **Nível 7:** um caixa eletrônico

## Como rodar

No terminal, dentro da pasta `python-1`, é só digitar:

```
python nivel_1/ex1_operacoes.py
```

Pra rodar outro exercício, é só trocar o nome do arquivo.
