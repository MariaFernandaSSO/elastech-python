# Python 2

Essa é a minha segunda atividade de Python! 🐍

Agora os exercícios são sobre listas, dicionários, sets, strings, funções e classes.

## O que tem em cada pasta

- **1_listas:** criar lista, append, insert, pop, soma, maior e menor
- **2_dicionarios:** notas das alunas, get, keys, values e items
- **3_sets:** nomes repetidos, interseção, união e diferença
- **4_strings:** maiúsculas, minúsculas, strip, replace, split e join
- **5_funcao_vs_metodo:** funções somar e saudacao, e um método dentro da classe
- **6_classes:** classe Aluna com \_\_init\_\_, média e \_\_str\_\_

## Função x método

A função é solta e chamada pelo nome. O método fica dentro da classe e é chamado pelo objeto.

## Como rodar

No terminal, dentro da pasta `python-2`, é só digitar:

```
python 1_listas/ex01_lista_nomes.py
```

Pra rodar outro exercício, é só trocar o nome do arquivo.
